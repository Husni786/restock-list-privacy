## Play Console

Paste the live URL into **Play Console → Dashboard → Privacy Policy → Privacy policy URL**.

## Updating the policy

1. Edit `privacy-policy/index.html` in this project.
2. Update the same file in the GitHub repository (web editor or git push).
3. GitHub Pages redeploys automatically, usually within a minute.

The page is a static, self-contained HTML file with no external scripts, fonts, or trackers.
